# みんなでパーティーゲーム（オンライン版）

URLを送るだけで、友達それぞれのスマホでオンライン対戦できるパーティーゲーム集です。

- **ワードウルフ**：自分のお題がそれぞれのスマホに届く。投票もオンラインで集計
- **数字ならべ**：数字がこっそり配られる。たとえ話で小さい順に並ぶ
- **ぴったり10秒**：全員が同時に挑戦。10秒に近い順にランキング

## 遊び方

1. ひとりが「ルームを作る」→ 出てきた招待リンクを友達に送る
2. 友達はリンクを開いて、ニックネームを入れて「参加する」
3. ホストがゲームを選んで開始

チャット機能はないので、通話しながら遊ぶのがおすすめです。

## 仕組み

GitHub Pages（静的ホスティング）だけで動かすため、ブラウザ同士を直接つなぐ WebRTC を使っています。
つなぐ相手を見つける仲介だけ [PeerJS](https://peerjs.com/) の無料の公開サーバーを利用します（名前とゲームの情報は仲介サーバーを通りません）。
ホスト役の端末がゲームの進行を管理するため、ホストが画面を閉じるとゲームは終了します。

## 注意

- 学校やお店のWi-Fiでは通信がブロックされてつながらないことがあります。その場合はモバイル回線で試してください。
- 無料の公開サーバーなので、混み合うとつながりにくいことがあります。
- ルームコードは友達にだけ教えてください。

## GitHub Pages で公開

Settings → Pages → Branch を `main` / `(root)` にして保存。
